# Family Devotion App

A simple static web app that provides a full-year (365/366 day) devotion calendar.
Each day includes:

- A short scripture.
- A William Branham sermon quote entry.
- A daily sermon reference marker.

## Run locally

Open `index.html` in your browser.

## Notes

- The app renders every day of the selected year and assigns a unique daily pairing via deterministic indexing.
- Author information has been added in the footer exactly as requested.
